# Car Home — لانشر لسيارة جيتور G700

شاشة رئيسية (Launcher) مستقلة تماماً عن تطبيق New Trip. تقرأ بيانات السيارة بنفس طريقة TripLog (Autolink عبر `CarBridge`).

## الميزات
- **منطقتان على الشاشة الرئيسية:** يمين ويسار، في كل منهما تطبيق مختلف في آن واحد (مثل الملاحة + يوتيوب)، أو **لوحة السيارة** المدمجة (سرعة، نمط القيادة/PARK، غِيار، بطارية، وقود، مدى، kW، rpm، عدّاد).
- **تعديل الحجم:** زر «تعديل» في الفاصل ← اسحب ◀ ▶ ← «تم».
- **اختيار الشاشة:** قائمة منسدلة أسفل اليسار: Display 0 (Front) افتراضياً، و Display 5 (Rear). أي تطبيق يُشغَّل يذهب للشاشة المختارة.
- **شريط المفضلة:** حتى 5 تطبيقات تحددها أنت + زر «التطبيقات» لفتح المكتبة الكاملة. اضغط على تطبيق ليعمل في المنطقة المحددة (الإطار الأزرق)، أو مطوّلاً للتثبيت/ملء الشاشة/المعلومات/الحذف.
- **زر WIDGETS:** لإضافة الودجات (حالياً: لوحة السيارة؛ والباقي لاحقاً).
- **الوصول من أي شاشة:** أيقونة عائمة قابلة للسحب ⌂، وخيار السحب من حافتي الشاشة (⚙ ← إعدادات Car Home).
- **التحديث الذاتي** وصفحة التثبيت بالمتصفح عبر USB.
- معرّف التطبيق `com.carhome.app` (مستقل عن غيره).

## تنبيه مهم: تشغيل تطبيقين معاً
يعتمد على «النوافذ الحرة» في أندرويد (Freeform) التي يقرّر نظام السيارة إن كانت مسموحة. صفحة التثبيت تفعّل `enable_freeform_support` و `force_resizable_activities` (قد تحتاج إعادة تشغيل السيارة). بعدها افتح ⚙ ← «فحص قدرات النوافذ والشاشات» لترى ما يدعمه نظامك. إن لم تدعمها السيارة فسيعمل Car Home كشاشة رئيسية مع لوحة السيارة، ويُشغَّل التطبيق بملء الشاشة بدل المنطقة.
بعض التطبيقات لا تقبل تغيير الحجم، وبعض الأنظمة تمنع التشغيل على الشاشة الخلفية لغير تطبيقات النظام.

## البناء
1. أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد.
2. تبويب **Actions** ← يعمل **Build Car Home APK** تلقائياً، ثم حمّل `CarHome.apk` من **Releases**.
3. (اختياري) سرّ `SIGNING_KEY` ليتحدّث التطبيق فوق النسخة السابقة (وإلا يُولَّد مفتاح مؤقت لكل بناء).
4. لصفحة التثبيت: Settings ← Pages ← Source: **GitHub Actions**.

## التثبيت على السيارة
افتح صفحة التثبيت (`https://<حسابك>.github.io/<المستودع>/`) من Chrome/Edge، وصّل السيارة بـ USB (بعد تفعيل ADB)، واضغط «ثبّت».

## جعله الشاشة الرئيسية
اضغط زر **Home** في السيارة ← اختر **Car Home** ← «دائماً». إن لم يظهر الاختيار فقد يكون نظام السيارة يمنع تغيير اللانشر؛ التطبيق يعمل حينها كتطبيق عادي.
للرجوع للأصلي: الإعدادات ← التطبيقات ← Car Home ← مسح الإعدادات الافتراضية.

> غير تابع لجيتور أو شيري أو أوتولينك، وقد يتوقف بعد تحديث النظام. استخدمه على مسؤوليتك.
